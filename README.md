# Project 14 — Campus Placement Assistant

A Flask-based RAG assistant built with Python, LangChain, LangGraph, and ChromaDB. It answers placement-policy questions from three local text documents and uses deterministic Python rules to match student profiles against three fictional companies.

## Features

- Document Q&A using similarity retrieval (up to 3 chunks).
- Retrieved source filenames displayed separately from the answer.
- LangGraph conditional routing for Q&A and company matching.
- `match_placement_companies` LangChain tool with typed parameters and deterministic criteria.
- Shows every failed criterion for each ineligible company.
- Re-ingestion rebuilds ChromaDB to avoid accumulating duplicate chunks.
- No login, conversation memory, external job searches, or real recruitment actions.

## Requirements

- Python 3.10 or newer (Python 3.11 recommended).
- An OpenAI API key for chat and embedding models.
- VS Code with the Python extension.

## Setup in VS Code

Open this folder in VS Code, then open Terminal → New Terminal.

### 1. Create and activate a virtual environment

Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install packages

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Configure API key

Copy `.env.example` to `.env` and replace the placeholder with your API key. Never commit `.env` or share your key.

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

macOS/Linux:

```bash
cp .env.example .env
```

### 4. Ingest the documents

```bash
python ingest.py
```

Expected output includes the number of source documents and chunks. Run ingestion again whenever the knowledge documents change.

### 5. Start Flask

```bash
python app.py
```

Open the local address printed in the terminal (normally `http://127.0.0.1:5000`).

## Troubleshooting

- **ChromaDB not initialized:** run `python ingest.py` before `python app.py`.
- **Missing API key / authentication failure:** check `.env` and restart the terminal process.
- **Package/import errors:** activate `.venv`, then rerun `pip install -r requirements.txt`.
- **Port already in use:** stop the other Flask process or configure a different port.
- **Model access or API billing:** verify that your API account has access to the configured models.

Eligibility is a criteria match only; it does not guarantee an interview or employment.
